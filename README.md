# AegisDNS-AI-Powered-Threat-Intelligence-Analytics
An AI-driven DNS firewall and analytics suite featuring an interactive, futuristic dashboard. It detects malicious domains (DGA/Phishing) using lexical analysis and Shannon Entropy, providing Explainable AI (XAI) insights via SHAP for transparent blocking. Built with FastAPI, Next.js, and SQLite, it offers real-time threat visualization.
